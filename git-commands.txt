# Git Commands để push code lên nhánh mới

## 1. Khởi tạo Git repository (nếu chưa có)
git init

## 2. Thêm remote repository (thay YOUR_REPO_URL bằng URL thực tế)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

## 3. Kiểm tra trạng thái hiện tại
git status

## 4. Thêm tất cả files vào staging area
git add .

## 5. Commit với message mô tả
git commit -m "feat: implement MVC architecture with Repository, Service, Controller layers using raw SQL queries"

## 6. Tạo và chuyển sang nhánh mới
git checkout -b feature/mvc-refactor

## 7. Push nhánh mới lên remote
git push -u origin feature/mvc-refactor

## 8. (Tùy chọn) Nếu muốn push lên nhánh main
# git checkout main
# git push -u origin main

# ================================
# Lệnh rút gọn để chạy một lần:
# ================================

# Nếu đã có remote repository:
git add . && git commit -m "feat: MVC architecture with raw SQL" && git checkout -b feature/mvc-refactor && git push -u origin feature/mvc-refactor

# ================================
# Kiểm tra sau khi push:
# ================================
git branch -a  # Xem tất cả branches
git log --oneline  # Xem lịch sử commit
